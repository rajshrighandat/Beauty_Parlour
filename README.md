# 🌸 माऊली ब्युटी पार्लर (Mauli Beauty Parlour) Website

A modern, responsive, and luxurious website designed for **माऊली ब्युटी पार्लर**, built exclusively with **pure HTML5 and CSS3**.

> *"सौंदर्य तुमचे, काळजी आमची !"* (Your Beauty, Our Care!)

---

## ✨ Features

- **Royal Aesthetics:** Deep Wine / Burgundy and Gold luxury color scheme inspired by traditional Indian bridal elegance.
- **Pure HTML5 & CSS3:** No external heavy JavaScript libraries needed. Lightweight, fast-loading, and responsive.
- **Featured Services:**
  - 👑 सर्व प्रकारच्या ब्रायडल ऑर्डर (Bridal Orders & Styling)
  - 💄 मेकअप ऑर्डर (Engagement, Reception & Occasions)
  - 💖 साइडर मेकअप (Sider / Party / Family Makeup)
  - 🌿 ब्लिच व फेशियल (Bleach, Facial & Skincare)
- **Interactive Elements:**
  - Direct WhatsApp booking integration
  - Direct phone calling support
  - Floating mobile quick-action buttons
  - Bridal packages comparison & pricing
  - Photo gallery showcases

---

## 🚀 How to Run Locally

1. Clone or download the repository:
   ```bash
   git clone https://github.com/rajshrighandat/Beauty_Parlour.git
   ```
2. Open `index.html` directly in any web browser.

## 🛠️ Technologies Used
- HTML5 (Semantic elements & Marathi Devanagari typography)
- CSS3 (Variables, Flexbox, Grid, Glassmorphism, Responsive Media Queries)
- Google Fonts (`Rozha One`, `Yatra One`, `Tiro Devanagari Marathi`, `Poppins`)
- Font Awesome 6 Icons
